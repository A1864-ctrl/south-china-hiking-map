# 华南徒步地图 · Vue 3 前端

旧版是 Streamlit 应用（`Home.py` + `views/`），新版重做成纯前端单页应用，部署在 GitHub Pages。
数据与交互都在浏览器里，不依赖 Python 运行时。

- 线上地址：<https://a1864-ctrl.github.io/south-china-hiking-map/>
- 部署产物：仓库根目录 `docs/`（GitHub Pages 从这里发布）

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 框架 | Vue 3 + Vite 5 | `<script setup>`，无状态管理库 |
| 路由 | vue-router（hash 模式） | 子目录部署不需要服务端 rewrite |
| 地图 | Leaflet 1.9 + 高德瓦片 | WGS84→GCJ-02 纠偏，标准/卫星双图层 |
| 图表 | 手写 SVG | 高程剖面、排行条形图、散点图，零图表库 |
| 体积 | 356 KB JS / 58 KB CSS（gzip 138 / 15 KB） | 无图片依赖，Hero 用 CSS 渐变 + 数据化背景 |

## 页面

1. **项目说明** `/` — Hero 统计、三个功能入口、热门路线 Top5、热度城市 Top5、强度天花板、四步使用、安全贴士
2. **景点搜索** `/spots` — 关键词 / 城市 / 类型筛选 + 卡片列表 + 右侧联动地图；每张卡片可打开「路书」弹层（打卡机位、吃法、交通）
3. **徒步轨迹** `/routes` — 省份 / 难度 / 地形 / 关键词筛选 + 轨迹地图 + 里程爬升 + 途经点间距 + 高程剖面 + **分段路书** + 交通接驳 + 补给撤离 + 装备清单 + 风险提示 + 导出 GPX
4. **城市热度** `/heat` — 指标卡、综合热度排行、景点×路线散点、城市明细表

## 地图交互

- 滚轮**直接**缩放（不需要按 Ctrl），双击放大，右上角切「标准 / 卫星」
- 放大到 15-19 级可看街道与步道级别细节（高德瓦片 `maxNativeZoom=18`，18 级后自动超采样）

## 数据

`src/data/`

| 文件 | 内容 |
|---|---|
| `routes.js` | 51 条路线：湖南 23 条 + 广东 22 条 + 全国热门 6 条（武功山、黄山、华山、太白山、虎跳峡、雨崩）。每条含关键点（名称/经纬度/海拔/路书说明/补给/机位/营地）、交通接驳、装备、风险 |
| `spots.js` | 75 个景点：城市、区县、类型、热度、门票、时长、推荐理由、坐标 |
| `spotGuide.js` | 景点路书：打卡机位、推荐走法、交通、当地美食 |
| `geo.js` | 坐标纠偏、关键点→轨迹（Catmull-Rom + 自适应盘山摆动）、高程剖面、GPX 导出 |
| `cities.js` | 城市元信息与热度指数 |

> 轨迹是按**真实关键点**拟合的走线：控制点坐标取实际地点，段内用多次正弦摆动模拟盘山折返，使画出来的长度接近标注里程。
> 若要换成真 GPS 轨迹，把 `src/data/routes.js` 里对应路线的 `pts` 换成 GPX 解析结果即可，组件无需改动。

## 本地开发

```bash
cd web
npm install
npm run dev        # http://127.0.0.1:5178
npm run build      # 产物在 web/dist
```

## 更新到线上

```bash
cd web && npm run build
rm -rf ../docs/assets ../docs/index.html
cp -r dist/* ../docs/
```

提交并推送后，GitHub Pages 会在 1 分钟内更新（Pages 源：`master` 分支 `/docs` 目录）。
