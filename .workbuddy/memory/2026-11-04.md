- 需求来源：用户原项目 https://south-china-hiking-map.streamlit.app（Streamlit，左侧 sidebar + 三个模块），
  页面报 `TypeError: 未能获取动态导入的模块 .../~/+/static/js/*.js`；要求参考桌面 `户外徒步路线指南.html`
  的视觉重做前端，并把页面切换/功能切换改成顶部布局。
- 产出（工作区根目录）：Vue 3 + Vite + vue-router(hash) + Leaflet 工程，已 `npm run build` 通过。
  - `src/views/`：HomeView / SpotsView / RoutesView / HeatView
  - `src/components/`：TopNav、SiteFooter、HikeMap（Leaflet + 高德瓦片 + WGS84→GCJ02）、ElevationChart（SVG 高程）
  - `src/data/`：spots.js(75)、routes.js(34)、cities.js(热度指数)、geo.js（轨迹/高程生成、GPX 导出）
- 关键设计：顶部导航 4 页；筛选条全部在页面上方；景点页 左列表 + 右 sticky 地图联动；
  路线页 左列表 + 右详情（轨迹 + 高程 + 途经点 + GPX 导出）；热度页 指标卡 + Top 榜 + 观光/徒步散点。
- 数据为示例数据（真实地点名 + 演示热度/票价），README 写了替换真实数据的方法。
- 已验证：1440px 桌面 4 页截图、360/390px 移动端无横向溢出、城市筛选 → 列表与地图联动正常。
- 报错结论：Streamlit 未锁定版本 + redeploy 后旧 chunk 失效 / 插件拦截 / 国内访问 static 资源失败，
  排查顺序：无痕强刷 → Reboot app → pin requirements 版本重部署 → 换网络。
