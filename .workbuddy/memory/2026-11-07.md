- AuthDialog 重写：手机/邮箱验证码双 Tab（60s 倒计时、格式校验、禁用态防误点）+「或一键登录」分隔 + 微信/WorkBuddy 两按钮；错误映射「未开通→去设置-数据管理-应用打开」。

- 坑：v-model 绑定三元表达式别用（改 v-if/v-else 双输入框）；bash heredoc 里模板字符串反引号会被 shell 吃掉——复杂 CDP 脚本一律写 .mjs 文件执行；重建后 hash 变化导致快照 cp 失败——先写完所有文件再一次性构建+部署。
